# 《一个人的 AI 团队》Treatment

这里记结构选择；完整做法见仓库根目录 README.md 和 prompts/。

## 三种候选结构

1. **聊天串起来的两章式**（照 Overlay Studio 宣传片的结构）：群聊开场，角色跳出屏幕 → 第一章：工作室怎么转（5 步）→ 第二章：这条片子怎么做的 → 统计卡 → 回到群聊领提示词。
2. **一天的时间线**：早上 07:15 知识库自动更新 → 白天派活 → 夜里借用机跑长任务 → 第二天早上交付。故事感强，但"怎么用"被时间切碎，每一步讲不透。
3. **三个角色各一段**：Claude 篇、Codex 篇、Grok 篇，最后汇合。角色突出，但"一个人统筹"这条主线变弱，像三个产品广告拼在一起。

## 选择：1

沿用原片结构：它最适合"讲清怎么用"：每一步一个大号步骤名 + 一块真实界面，观众记得住。2 里的"夜里跑"放进第一章第 3 步，3 里的"各自花样动作"放进开场三人依次跳出。

## 不变的约束

- 全程代码驱动，0 个手调关键帧；`timeline.py` 是唯一真值。
- 竖屏 1080×1920 / 30fps，文字在安全区 x 60–880、y 270–1420 内。
- 统计卡的数字构建时现数，不抄原片的 5,544 / 2,756。
- Codex（白壳、黑眼睛「>_」）和 Grok 是自己设计的形象；画面不加"非官方"小字。
